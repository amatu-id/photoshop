# Amatu Photo

Editor foto berbasis layer di browser dengan alur kerja ala Photoshop — tanpa build, vanilla ES modules.

**Live:** https://amatu-id.github.io/photoshop/

- Layer, grup, layer mask, clipping mask, 27 blend mode, opacity & fill
- Adjustment layer (Levels, Curves, Hue/Saturation, Color Balance, dll.) dan fill layer
- Layer Style: Drop Shadow, Inner Shadow, Outer/Inner Glow, Bevel & Emboss, Satin, Overlay, Stroke
- 60+ tool: seleksi (Marquee, Lasso, Magnetic, Quick Selection, Magic Wand, Object Selection), Crop, Brush/Pencil/Mixer, Clone/Healing/Spot Healing/Remove (Content-Aware), Patch, Eraser, Gradient, Dodge/Burn, Pen & Shape, Type
- Free Transform (scale, rotate, skew, distort, perspective), Liquify, Camera Raw Filter, Select and Mask, Color Range
- Filter Blur/Distort/Noise/Pixelate/Render/Sharpen/Stylize/Other
- Buka/ekspor PSD (ag-psd), PNG/JPEG/WebP, simpan proyek di browser (IndexedDB)
- Tema Liquid Glass (gelap, terang, aurora, senja) + tema klasik 4 tingkat kecerahan

Deploy: commit lalu `git push` (GitHub Pages, branch `main`, root).
